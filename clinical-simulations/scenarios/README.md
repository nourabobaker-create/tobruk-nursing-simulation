# Clinical placement scenarios

Thirteen bilingual educational topics, each with four sequential decisions and explanations for all three choices. The collection covers placement orientation, paediatric communication, orthopaedic mobilisation questions, patient choice in maternity care, dressing preparation, reporting clinical change, theatre boundaries, neonatal alarms, surgical handover, delivery-room communication, cardiac reporting, emergency-department roles and adult monitor alarms.

Each topic lists its own primary sources, the principle supported and the access date. Case wording is original educational material. Local placement protocols and supervised assignments remain the authority for actual tasks; the material does not establish new student permissions, independent device operation or treatment rules.

## Learner behaviour

- Arabic and English are complete interfaces; the existing simulation-language preference is reused.
- Choices are reordered deterministically per scene. A learner can correct an unsuitable choice and read its explanation before continuing.
- First-choice feedback is private learning feedback, not a course grade or competency assessment.
- Answers and progress are held only in the current page's memory and reset on reload.
- Optional portal analytics record only activity start/completion with topic ID and the existing consent controls. They do not receive answer selections or scores. Completion means reviewing all four decisions.
- English scene audio is learner initiated and depends on browser speech support.
