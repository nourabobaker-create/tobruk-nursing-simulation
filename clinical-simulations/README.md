# Tobruk advanced clinical simulations — release 20261005-1

Ten delivered HTML teaching prototypes. Module files are byte-for-byte copies of the delivered simulations; SHA-256 values are in manifest.json. CPR uses the revised clinical-figure version.

## Scope and approval
Clinical instructor approval is pending. CPR is adult-only: infant/newborn resuscitation is not implemented. Catheterization is the adult-female indwelling pathway. Blood extraction is the adult syringe pathway. Gown/diaper movement uses an adult bedside model. Read each module's embedded source adaptations and limitations. No clinical corrections were made in this publication step.

## Structure
index.html / library.css / library.js: bilingual accessible catalogue; modules/: independent original HTML files; previews/: thumbnails of previously delivered screenshots; assets/: existing faculty/university logos; portal-link.js: additive links for existing hub and seven-skill library.

## Maintenance
Keep original modules and manifest in version control. Replace an approved module deliberately, update its SHA-256 and release version, test from the actual public route. Do not treat page visits, fictional practice records, or software checks as clinical competence. Do not publish real student/patient records. No font files, tracking services or new grade database are included.
