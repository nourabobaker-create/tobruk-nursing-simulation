# Patient Positioning — Learning 01
Faculty of Nursing — Tobruk University. Skill 06.

## Source coverage
Primary sources: `6. Positioning--.docx` and `6.Positioning.docx`. Each has eleven entries, but they are not identical. Twelve learning topics map their combined coverage without changing either source file. The source guide preserves original numbers, complete substeps, exact English source text, and supplied rationales. Arabic is a teaching translation. Horizontal recumbent is notes-only; High Fowler's 90 degrees is checklist-only. The 45-degree card displays both the notes' Fowler's label and the checklist's Semi Fowler's label. Supine is kept separate from Horizontal recumbent. No rationale is invented for Supine or High Fowler's. The checklist's 33-point clinical score is not awarded by this app.

## Learning features
Learn, Train, Scenario test, Source guide, and 24-question written practice. The articulated clothed mannequin has angled, side and overhead views. Related positions can be compared side-by-side. Permitted arm and support alternatives are accepted, not treated as wrong merely because a default differs. A percentage indicator measures screen movement; the clock records active interaction, with no speed target. Students review incorrect choices, answer explanations, related lessons and retry only missed written questions. Scenario records retain first choices after correction. Safety pause invalidates readiness without counting as an incorrect decision.

## Disclosed limits
The source gives position features, not complete patient transfer or examination techniques. Added explanation and safety notes are separately labelled. Sims says either side but names fixed left/right limbs: a disclosed left-side example is used without inventing the opposite-side instructions. Prone head/airway protection during the illustration is an added safeguard. The source label Trendelenburg (Shock Position) and its rationale are retained for traceability, not endorsed as routine shock treatment. The additional AHA/Red Cross first-aid note differentiates supine/selected leg elevation from whole-bed head-down tilt. A live patient requires an individual clinical plan, suitable assistance/equipment and supervision. The app does not measure force, pressure, breathing, balance or patient suitability.

## Hosting and offline files
This directory is self-contained on a static web server. The four compact row files and additional questions are expanded deterministically into the source-mapped dataset; the browser loader compiles them around a pinned local engine copy. No previous module is modified. Save offline embeds the compiled code, styles and both logos in one HTML file. No login, analytics or persistent student records. Reloading clears answers.
