# Tobruk Nursing Skills — all six
Faculty of Nursing — Tobruk University.

A bilingual shared home and navigation shell for the six completed teaching prototypes. Existing individual modules and their content are not overwritten. The latest Clean Gloving Learning 01 is included here; it is not the older clean-gloving demonstration.

## Included
1. Medical Handwashing, Learning 03: 24 written questions.
2. Clean Gloving, Learning 01: 25 written questions.
3. Range of Motion, Learning 01: 24 written questions plus visual recognition.
4. Proper Body Mechanics, Learning 01: 24 written questions.
5. Turning and Moving Patient, Learning 01: 24 written questions.
6. Patient Positioning, Learning 01: 24 written questions.

All original explanations, source qualifications, demonstrations, tests and safety notes remain in their modules. No merged clinical competency score is awarded. The home tracks opened modules in this tab, not completion. No login, tracking scripts or server-submitted answers are added.

## Navigation and state
Modules open in isolated same-origin frames. Switching or returning home retains the current page and answers while the tab remains open. Inactive frame animation queues are suspended. Language changes synchronise between the shell and active module. Cross-module links open the appropriate cached module. Closing or reloading clears this in-memory session.

The online hub loads the existing sibling module folders. Clean Gloving is restored from seven base64 raw-DEFLATE parts, in the explicit loader order; a bounded local decoder requires exactly 101353 decoded bytes before embedding the same supplied logos. Part hashes were verified before publication. The decoded teaching code is not rewritten.

## Offline export
Save all six offline embeds the complete HTML, code, styles and logos for every module. The downloadable standalone and ZIP supplied with this release already contain all six, and do not depend on repository-relative paths. Export starts a fresh session without the current answers. On phones that cannot open HTML attachments, use the hosted URL instead.

## Verification
96 Chromium integration checks passed for desktop and phone-sized touch emulation: all six initialisations, navigation, language synchronisation, correct question counts, explanation display, answer retention, cross-module links, hidden-loop pause, and complete offline export/reopening. The compressed Clean Gloving loader was separately tested with the actual staged parts and shared logos. Tests used browser content injection because live browser navigation was restricted in the test environment. This is software verification, not clinical validation or testing on a physical iPhone.
