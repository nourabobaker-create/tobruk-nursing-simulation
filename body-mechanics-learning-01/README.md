# Proper Body Mechanics — Learning 01
Faculty of Nursing — Tobruk University. Module 04.

Independent module; earlier handwashing, gloving and movement modules are not modified.

## Learning experience
Seven source topics: lifting a light object; shelf placement; supported golfer's tee pickup; pivoting; pushing a suitable trolley; desk posture; periodic stretching. Four stretch demonstrations retain shoulder squeeze/relax, both shoulder-roll directions, and a clearly limited standing posture illustration.

Learn: animated examples, pause/replay, slower playback, manual motion slider, source-derived rationale and explicitly labelled added guidance.
Train: choose the setup, correct inappropriate choices, move the articulated model, then answer an understanding question. The desk accepts either floor support or a footrest.
Scenario test: independent setup decisions and movement, recorded first choices, correction history and review. An inappropriate setup cannot start movement; feedback can be requested. This is not an unconstrained physical simulator or clinical assessment.
Written practice: 24 questions; immediate-feedback and end-review modes, explanations for every answer choice, lesson links, focused retry, optional self-reflection.

## Source and scope
Primary sources are the supplied 4. Body Mechanics--.docx procedure/rationale sheet and 4.Body Mechanics.docx checklist. All seven topics are mapped in source order; original English wording is visible in the source guide. Arabic is a teaching translation. Source explanations are separate from additional safety/illustration notes. The checklist's 21-point clinical score is not awarded by this app.

This module concerns object handling and personal posture, not manual patient lifting. Body mechanics alone does not establish patient-handling safety. External safety references are linked in the app. The source does not define load limits, personal suitability criteria, or a back-stretch direction/dose; the example limits are explicitly labelled rather than presented as source instructions.

Percentages and active time describe screen interaction, not measured spinal load or a safe real-world range. No speed target or medical exercise dose is invented.

## Hosting and privacy
Open index.html through a static HTTPS host. All runtime assets are local to this directory. Save offline exports a single HTML file with code, styles and logos embedded. No accounts, analytics, student names, persistent answer storage or external runtime libraries. External references are opened only when clicked; normal hosting request logs are controlled by the host.
