# Institutional Quality Management Prototype

نموذج تفاعلي لمنظومة الإدارة المؤسسية والجودة – كلية التمريض، جامعة طبرق.

## الغرض
عرض تجربة الاستخدام المقترحة قبل بناء النسخة الإنتاجية على خادم الجامعة.

## الأدوار في النموذج
- العميد: لوحة تنفيذية واعتمادات واستلام وتسليم.
- قسم ضمان الجودة: إدارة المهام والوثائق والشواهد والتحسين.
- تقنية المعلومات: دعم فني ونسخ احتياطي واستعادة عند الحاجة.
- الموظفون: تطبيق مبسط حسب الدور الوظيفي.

## ملاحظات مهمة
- هذه نسخة GitHub Pages ثابتة.
- لا يوجد تسجيل دخول حقيقي.
- لا تُرفع الملفات إلى خادم.
- التغييرات التجريبية تحفظ في localStorage داخل المتصفح فقط.
- زر «إعادة النموذج» يعيد بيانات المحاكاة.
- لا تستخدم النسخة لإدخال بيانات شخصية أو حساسة أو وثائق حقيقية.

## المسار الإنتاجي المقترح
خادم جامعة طبرق + مصادقة فردية + RBAC + قاعدة بيانات + تخزين مؤسسي + Audit Trail + Backups + تطبيق موظفين PWA.
