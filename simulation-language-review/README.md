# مراجعة العربية في المحاكاة — 20261005-ar2

## نطاق المراجعة
تشمل المراجعة الوحدات الـ17 النشطة في مكتبتي المحاكاة المرتبطتين بالبوابة: المهارات السبع السابقة والوحدات العشر المتقدمة. لا تعني هذه العبارة فحص كل رابط أرشيفي أو نموذج أولي غير مستخدم في المستودع.

المهارات السابقة: غسل اليدين الطبي، القفازات النظيفة، مدى الحركة، ميكانيكا الجسم، تقليب المريض وتحريكه، وضعيات المريض، وتغيير ضماد الجرح.

المتقدمة: الإنعاش القلبي الرئوي للبالغين، الاختناق، تخطيط القلب، إدخال الأنبوب الأنفي المعدي، إزالته، سحب الدم، القسطرة البولية للأنثى، الأربطة، الاستنشاق بالرذاذ، وتغيير الثوب والحفاض.

## نتيجة التدقيق والإصلاح
كانت الوحدات العشر تتضمن ملخصات عربية للخطوات، لكنها تترك أجزاء مهمة من الواجهة والمبررات والأسئلة ورسائل التصحيح بالإنجليزية. أُضيفت ترجمات عربية مكتوبة لهذه النصوص، وشريط واضح لاختيار اللغة، واتجاه قراءة مناسب. احتُفظ بالمصطلحات الإنجليزية المطلوبة للتعلم وبالنطق الإنجليزي لكل مصطلح أو تعليمة على حدة. لا توجد قراءة عربية صوتية أو قراءة للصفحة كلها.

تحتوي المهارات السبع السابقة أصلًا على مسارات تعليم وأسئلة ثنائية اللغة. فُحص المحتوى الفعلي بعد فك تحميل الوحدات، وصُححت صياغة عربية ملتبسة في ميكانيكا الجسم، وأضيف اختيار مشترك للغة يبدأ بالعربية ويحفظ التفضيل أثناء الانتقال. بقيت الاقتباسات الإنجليزية الأصلية وأسماء بعض المراجع كما هي إلى جانب الشرح التعليمي العربي؛ لم تُقدَّم باعتبارها ترجمات عربية جديدة.

لم تتغير الأرقام السريرية أو مفاتيح الإجراءات أو الإجابات الصحيحة أو الرسوم التشريحية. أُبقيت الفروق بين نص الملف وملاحظات السلامة المضافة. تعديل العرض الوحيد غير اللغوي هو منع محاولة تحديث عنصر اختيار غير موجود أثناء عرض سحب الدم. لا يعكس اتجاه العربية جوانب جسم النموذج أو مواضع الأقطاب.

## ما اختُبر
تقارير `local-new-browser-results.json` و`local-legacy-browser-results.json` تسجل الفحوص المحلية المنفذة: فتح الوحدات، العربية، تبديل اللغة، عرض لوحات المصادر والأسئلة المتاحة، وبدء العرض الحركي للوحدات العشر، مع شاشة ضيقة بعرض 390 بكسل. لم تظهر أخطاء JavaScript في الجولة النهائية. هذه البيئة المحلية استخدمت تحميل المحتوى داخل المتصفح، لا فتح المسار المنشور.

يقوم `verify_browser.py` بفحص مستقل عبر خادم HTTP فعلي: المسارات الـ17، العربية الافتراضية، حفظ التفضيل بعد إعادة التحميل، عدم تغير قيم النماذج عند الترجمة، حفظ حقول JSON الأصلية، والانتقال بين إطارات المهارات السبع والمكتبة الجديدة. سجل التنفيذ الآلي، وليس مجرد وجود الاختبار، هو مرجع نجاح هذه الجولة. يُحفظ التقرير المنفذ في `verified-browser-results.json` بعد نجاح الفحص.

لا تمثل فحوص المتصفح اعتمادًا سريريًا أو اختبارًا لكل سيناريو وحركة على جهاز فعلي. تبقى المراجعة السريرية واختبار هواتف الطلاب مطلوبين. لا ندعي أن كل اقتباس مرجعي إنجليزي أصبح عربيًا أو أن الفحص الآلي يثبت جودة كل لفظ طبي نهائيًا.

## صيانة الترجمة
ملفات `translations/*.json` تربط النص الإنجليزي الأصلي بترجمته العربية. الرموز ⟦0⟧ وأخواتها متغيرات يجب المحافظة عليها. لا تعدل معرفات الإجراءات أو قيم الاختيارات أو الإجابات الصحيحة بهدف الترجمة. يحتوي كل HTML متقدم على نسخة مدمجة من القاموس و`locale-runtime.js` لتظل النسخة المنزلة مستقلة. يحتفظ `native-bridge.js` باختيار اللغة في الوحدات السابقة باستخدام وظائفها الأصلية.

عند إضافة نص جديد: أضف ترجمته، أعد تضمين القاموس، حدّث البصمة في `clinical-simulations/manifest.json`، ونفّذ فحص اللغتين. سير العمل `Simulation language regression checks` يعيد الفحص عند التغييرات ذات الصلة. لا تمسح التخزين المحلي للطلاب لتجديد الواجهة؛ استخدم رابط الإصدار المحدث.
