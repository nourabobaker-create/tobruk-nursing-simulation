# مساحة الاعتماد — كلية التمريض، جامعة طبرق

واجهة عربية عامة مبنية على المعايير العشرة و١٨٤ مؤشراً من دليل الاعتماد المؤسسي، الإصدار الرابع ٢٠٢٣، مع ٣٥ مهمة من خطة تفعيل الجودة ١.٤.

## الحالة الحالية

هذه نسخة تأسيسية للعرض. ملف `public-progress.json` يفهرس ٢٠ مصدرًا موجودًا ومقروءًا مرتبطًا مبدئيًا بـ٥٦ مؤشرًا، مع ٢٢ سجلًا لممارسات وأعمال موثقة بالمشروع. نسبة تغطية المصادر لا تعني نسبة استيفاء الاعتماد. لم يُفعّل التحديث الآلي والحفظ الجماعي بعد. لا تحفظ هذه الواجهة تعديلات في ذاكرة المتصفح على أنها بيانات مشتركة.

## الملفات

- `index.html`: الواجهة
- `style.css`: التنسيق
- `app.js`: العرض والبحث والتصفية
- `public-progress.json`: البيانات العامة الأولية فقط
- `config.js`: رابط خدمة الملخص العام ورابط مساحة الفريق بعد تشغيلهما

## الربط اللاحق

يُضبط `summaryEndpoint` بخدمة عامة للقراءة فقط و`teamUrl` بمساحة كتابة موثقة الهوية. يجب ألا يتضمن ملف الإعدادات كلمات مرور أو رموز وصول. صلاحية عرض البيانات لا تمنح صلاحية تعديلها. يجب اختبار التعديل بحسابين قبل إعلان جاهزية العمل الجماعي.

## النقل إلى الجامعة

يمكن تنزيل هذا المجلد ورفعه على أي استضافة ثابتة. تشغيل الوظائف الجماعية يتطلب نقل خدمة الخلفية والبيانات أيضًا. كود الواجهة لا يعتمد على اشتراك ChatGPT أو وجود Nokta. حذف المستودع بعد النشر لا يمحو النسخ التي قد يكون الآخرون حفظوها.

النسخة العامة لا تتضمن بريد الأعضاء أو سجلات التدقيق أو البيانات الفردية. يعرض فهرس الشواهد وصف الوثائق الموجودة وحالتها وروابط المصادر المتحققة عند توافرها. قد تتطلب روابط الملفات صلاحيات المصدر الأصلية. لم تُمنح قبولًا نهائيًا تلقائيًا لأي مؤشر.


## تحديث 3 أكتوبر 2026 — طبقة التكامل

أضيفت حزمة `google-backend/Integration.gs` لربط **Google Forms Responses + وارد Drive + سجل أثر التحديثات + Google Calendar** بنظام المعلومات المؤسسية. الكود موجود ومراجع صياغيًا، لكنه **ليس تشغيلًا آليًا معلنًا بعد**: يلزم تفويض مشروع Apps Script من حساب الجامعة وتشغيل `verifyIntegrationSetup` ثم `installIntegrationTriggers` واختبار دورة كاملة.

قاعدة التشغيل: لا يكتب النظام فوق الوثيقة المرجعية الأخيرة. كل تغيير جوهري يولد سجل أثر؛ وإذا استلزم وثيقة جديدة فيصدر ملف/إصدار جديد وتراجع الجودة انتقال Current/Superseded. الردود الخام للاستبانات تبقى في Response Sheets المقيدة ولا تنتقل إلى GitHub أو الواجهة العامة.
