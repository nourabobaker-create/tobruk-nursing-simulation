# Handwash Nano 02
Faculty of Nursing — Tobruk University.

One sink, direct cartoon-hand control, Arabic/English, Learn/Train/Test modes. The original nano remains in `nano-01.html`.

## Run
Open `index.html` through GitHub Pages or a local static server. The page uses only the local `nano02.js` script. Save offline exports a complete single HTML file with its executable code embedded. No CDN, account, analytics, student data storage or network-dependent assets.

## Coverage
Fifteen movements: palms; each back; interdigital rubbing; backs of fingers/knuckles; each thumb; individual fingers on both hands; each wrist; each forearm; fingertips/nail edges in opposing palms. Direct motion controls the rig. The training clock pauses when movement stops. Learn demonstrations earn no training credit. Test mode records missing movements and sequence/safety events rather than awarding the supplied paper checklist's clinical score.

## Curriculum and limitations
Based on the supplied Medical Asepsis—Medical handwashing procedure and eleven-action assessment sheet. Source adaptations are explicitly described in the app's Training notes & sources. Core friction uses 30 active seconds followed by 6 seconds of fingertip practice; these per-area timings are interaction targets, not clinical requirements. WHO whole-procedure duration differs from the active-rubbing timer.

Fingertip-in-palm rubbing is an added WHO-based exercise. The supplied sheet's under-nail debris-removal method is NOT demonstrated or assessed; this remains a practical verification item. Percentage is interaction progress, not measured cleanliness. Body position, pressure, actual skin contact and real competency require in-person observation.
