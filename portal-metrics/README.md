# مؤشرات بوابة كلية التمريض — الإصدار الأول

الرابط: https://nourabobaker-create.github.io/tobruk-nursing-simulation/portal-metrics/

## حالة التشغيل

- واجهة قياس حقيقية؛ لا توجد أرقام تجريبية أو استرجاع مزعوم لزيارات سابقة.
- المتتبع مضاف لصفحات البوابة المبينة في `coverage.json`. يبدأ القياس بموافقة الزائر من «قياس الاستخدام والاستفادة» أسفل الصفحة. رفض القياس لا يؤثر في الخدمات.
- `endpoint` في `config.js` فارغ عند التسليم. لذلك الأرقام المتاحة تخص المتصفح الحالي، والتجميع المشترك **غير مفعّل**. لا تُجمع أجهزة مختلفة أو تُنقل بيانات للجمع المشترك قبل تفعيله واختيار الزائر المشاركة.
- الخطوة المتبقية لتجميع جميع الزيارات المشاركة: نشر جامع Apps Script من حساب الكلية وإضافة رابط `/exec` إلى `config.js`؛ انظر [تعليمات التفعيل](backend/README.md). الجدول يبقى خاصًا. لا تتطلب اللوحة خدمة ذكاء اصطناعي.

## تعريفات المؤشرات

| المؤشر | المصدر والحدود |
| --- | --- |
| الجلسات | معرف مؤقت للجلسة، يتجدد بعد 30 دقيقة خمول؛ علامات التبويب قد تنتج جلسات مختلفة. ليست عدد أفراد. |
| التصفح | فتح صفحة أو قسم؛ لا يدل على قراءة أو تعلم. الصفحات المخفية في إطارات البوابة لا تُعد تلقائيًا. |
| فتح مصدر | نقر رابط خارجي أو تنزيل من الصفحة؛ لا يثبت اكتمال القراءة أو التنزيل. لا يُرسل عنوان الرابط أو استعلامه. |
| فتح خدمة | الانتقال إلى نموذج خارجي؛ ليس تقديم طلب أو شكوى. |
| أنشطة بدأت | تفاعل مع شرح حقل في الأطلس، أو التحقق من إجابة تمرين في لغة إنجليزية 2؛ النطاق موثق، ولا يشمل كل المحاكاة. |
| أنشطة اكتملت | أول انتقال للنجاح في تمرين مدعوم بلغة إنجليزية 2؛ لا تتضمن درجات أو إجابات. لا تمثل اجتياز مقرر أو كفاءة سريرية. |
| الإفادة | سؤال اختياري مرة لكل قسم وجلسة: أفادني / لم يفدني بعد. نسبة الإفادة من المجيبين فقط. |
| الطلبات الملباة والأثر التعليمي | لا تتوفر حتى ربط سجلات النماذج وقياس قبلي/بعدي مناسب؛ لا تُستنتج من الزيارات. |

لا تدمج اللوحة بيانات الجهاز بملخص مشترك أو بملف مستورد. تتوفر فلاتر الفترة والقسم، وتصدير CSV والطباعة. استيراد الملخصات يقبل المخطط المجمع فقط دون معرفات جلسات أو معلومات أفراد.

## جمع البيانات والخصوصية

المخطط: نوع حدث، قسم، معرف عنصر تقني، لغة، وقت، معرف حدث لمنع التكرار، ومعرف جلسة مؤقت. لا أسماء أو بريد أو أرقام دراسة أو كلمات بحث أو ملاحظات أو أسئلة أو إجابات أو بيانات مرضى. لا تُدرج معاملات URL في الأحداث. تحفظ البيانات المحلية 90 يومًا بحد 12,000 حدث؛ قد تقصر التغطية عند بلوغ الحد. مسح هذا الجهاز لا يحذف بيانات سبق استلامها مركزيًا.

المشاركة في الخادم اختيار منفصل. لا تعاد مشاركة السجل المحلي القديم تلقائيًا. النقل عبر Apps Script لا يوفّر تأكيدًا مقروءًا في المتصفح؛ تتم ثلاث محاولات بحد أدنى خمس دقائق بينها وبنفس معرف الحدث، ويمنع الخادم التكرار. تظهر حالة عدم التفعيل أو فشل القراءة، ولا يُستبدل بها الإجمالي المحلي بصمت.

## التحقق

`node --test portal-metrics/tests/*.test.cjs`

فحص قبول تشغيلي بعد نشر الجامع: جهازان يوافقان على المشاركة، تفاعل معلوم في كل جهاز، ثم تحقق من الملخص المشترك ومنع مضاعفة العد عند إعادة الإرسال. بدون هذا الفحص لا يوصف الجمع المشترك بأنه يعمل.
