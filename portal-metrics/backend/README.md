# تشغيل الجمع المشترك لمؤشرات البوابة

الواجهة العامة تعمل على GitHub Pages. هذا الجامع الاختياري يضيف حفظًا مشتركًا للأحداث المجهولة في جدول Google Sheets خاص؛ القياس المحلي وحده لا يمثل جميع زوار البوابة.

## التفعيل مرة واحدة

1. من حساب الكلية في [Google Apps Script](https://script.google.com/) أنشئ مشروعًا جديدًا والصق `Code.gs` في ملف الشيفرة. لا تضف مفتاحًا أو بيانات اعتماد إلى مستودع البوابة.
2. شغّل الدالة `setupPortalMetrics` من المحرر وأكمل تفويض حساب الكلية. تنشئ جدولًا خاصًا وصفحتي `events` و`meta` ومحفز تنظيف يومي. إعادة تشغيلها تحافظ على البيانات.
3. اختر **Deploy → New deployment → Web app**: التشغيل باسم صاحب المشروع **Execute as me**، والوصول **Anyone**. إذا منع نطاق الجامعة الوصول المجهول، يبقى القياس المحلي صالحًا ولا يُعلن الجمع المشترك مفعّلًا.
4. انسخ **رابط التشغيل المنتهي بـ `/exec` فقط** إلى `endpoint` في `portal-metrics/config.js` وفعّل الجمع المشترك بحسب تعليمات ذلك الملف. لا تنشر رابط تحرير المشروع أو الجدول، ولا تشارك الجدول على الإنترنت.
5. افتح رابط التشغيل مضافًا إليه `?action=summary&days=30`. يجب أن يظهر JSON يحمل `ready: true` و`mode: "shared"`. قبل وصول أحداث فعلية تكون `rows` فارغة. اختبر من جهازين بعد الموافقة على مشاركة القياس، وتأكد من وصول الأحداث إلى اللوحة المشتركة.
6. عند تحديث الشيفرة اختر **Manage deployments → Edit → New version → Deploy**؛ حفظ الملف وحده لا يحدّث الإصدار المنشور.

`setupPortalMetrics` لا ينشر مشروعًا ولا يغيّر مشاركة الجدول. يتطلب النشر تنفيذ الخطوات أعلاه من حساب الكلية؛ وجود هذه الملفات في GitHub لا يعني أن الجمع المشترك يعمل.

## ما يُجمع وما يظهر

- المشاركة طوعية عبر متتبع البوابة. الأحداث تحمل معرف حدث ومعرف جلسة عشوائيًا قصير العمر؛ ليس هناك اسم أو بريد أو رقم دراسي أو معرف دائم للشخص.
- لا ترسل عبارات البحث أو نص الأسئلة أو الإجابات أو بيانات المرضى أو روابط تتضمن استعلامات شخصية. `item` معرّف تقني محدود ومحكوم بالأحرف المسموحة.
- يحتفظ الجدول الخاص بالأحداث الخام حتى 90 يومًا وبحد 50,000 حدث، ثم ينظّفها. يمكن أن تُقصّر كثافة الاستخدام مدة التغطية؛ تعيد الواجهة `coverageFrom` و`partialCoverage` لبيان ذلك.
- يعيد مسار القراءة العام **أعدادًا مجمعة يوميًا فقط**؛ لا يعيد معرفات الجلسات أو صفوف الأحداث أو رابط الجدول. فترة القراءة من يوم واحد إلى 90 يومًا بتوقيت ليبيا `Africa/Tripoli`.
- تُنسب الأحداث إلى يوم **استلام الخادم**. يحتفظ وقت الجهاز للتحقق فقط؛ الأحداث المرسلة بعد انقطاع الشبكة تظهر عند استلامها ولا تعيد كتابة تاريخ سابق.
- الجلسات ليست أفرادًا مختلفين. فتح مصدر خارجي ليس دليل قراءة أو تنزيل. فتح نموذج ليس طلبًا أو شكوى مستلمة. لا يثبت عدد الزيارات أثرًا تعليميًا.
- الردود الفعلية لطلبات المكتبة والشكاوى والاستبيانات غير متصلة بهذا الجامع (`formsConnected: false`). تبقى مؤشرات استلامها/تلبيتها غير متاحة حتى ربط مصدرها الحقيقي.

## الحدود وجودة الأرقام

- يقبل `POST` نص JSON من المخطط 1، حتى 25 حدثًا و24,000 حرف في الطلب؛ ويتحقق من أنواع الحقول والقيم المسموحة.
- تمنع أقفال Apps Script تداخل الكتابة، وتُرفض معرفات الأحداث المكررة خلال فترة الاحتفاظ. إعادة المحاولة تستخدم معرفات الأحداث نفسها.
- الحد الوقائي 2,000 حدث في اليوم للمشروع و250 حدثًا للجلسة في اليوم. هذه حماية استهلاك تقريبية وليست نظام مكافحة تزوير؛ أي شخص يعرف مسار الإرسال يستطيع محاولة إرسال أحداث منتحلة. تُستخدم الأرقام للمتابعة والتحسين بوصفها ملاحظات تقريبية، وليست سجلًا رقابيًا أو إثبات حضور.
- توفر Google Apps Script وخدمات Google وحصص الحساب قد تحد الجمع. لا يعني نجاح طلب متصفح `no-cors` أن الحدث حُفظ؛ تحقّق من الملخص/الجدول. عند فشل الجمع لا تُعرض بيانات محلية بوصفها بيانات مشتركة.
- لا يوفّر هذا الإصدار حذفًا أو كتابة إعدادات عبر مسار عام. صاحب الحساب يدير البيانات من الجدول الخاص والمشروع.

## عقد البيانات

طلب الكتابة:

```json
{"schema":1,"events":[{"id":"evt_random123","session":"ses_random123","at":"2026-10-21T12:00:00.000Z","section":"library","event":"resource_open","item":"catalog/item-1","language":"ar"}]}
```

القيم المسموحة للأقسام: `faculty`, `students`, `library`, `simulations`, `atlas`, `courses`, `guides`, `community`, `services`, `research`, `strategy`.

القيم المسموحة للأحداث: `page_view`, `section_view`, `resource_open`, `service_open`, `activity_start`, `activity_complete`, `feedback_useful`, `feedback_not_useful`.

القراءة: `GET ?action=summary&days=30` أو `GET ?action=summary&from=2026-10-01&to=2026-10-21`. يدعم `callback=pmCallback` لقراءة JSONP من GitHub Pages، مع اسم دالة بسيط محكوم بالأحرف المسموحة.

الملخص يتضمن: `schema`, `mode`, `ready`, `generatedAt`, `collectionStartedAt`, `timezone`, `from`, `to`, `coverageFrom`, `partialCoverage`, `retentionDays`, `rows` (`day`, `section`, `event`, `count`), `sessions`, `engagedSessions`, `sectionSessions`, `engagedSectionSessions`, `feedbackResponses`, `formsConnected`.
